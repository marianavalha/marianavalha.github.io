# Maria Navalha: a lâmina e a rua

Obra de estudo sobre Maria Navalha, entidade da malandragem, o Rio de Janeiro do pós-abolição e a força feminina nas religiões de matriz africana.

Site estático (HTML, CSS e JS), publicado em https://marianavalha.github.io/

- `index.html` início · `historia.html` os sete atos · `hoje.html` tradições e arquétipo
- `estante.html` livros · `fontes.html` fontes, método e créditos · `design.html` design system
